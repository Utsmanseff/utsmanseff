# Utsman — Portfolio

Personal portfolio site, built as two layers: a dark pannable **canvas** of project nodes, and cream **reading pages** for the projects worth a full write-up. Hospital and public-sector systems in South Kalimantan. Written for engineers, not HR — experience and education live in the CV, not here.

Live: <https://utsmanseff.vercel.app> — no custom domain is wired yet.

## Stack

- **Next.js 16** (App Router, Turbopack, static prerender)
- **React 19** (concurrent renderer, React Compiler)
- **Tailwind CSS 4** (`@theme` design tokens)
- **Vitest + Testing Library + happy-dom**
- **next/font** (Fraunces · Inter · JetBrains Mono via `next/font/google`)
- **lucide-react + react-icons/si** (UI + brand icons)

## Run

```bash
npm install
npm run dev                       # http://localhost:3000
npm test                          # vitest run — 79 tests
npx eslint src --max-warnings=0   # lint (scoped to src; .claude/** is excluded)
npm run build                     # production build
npm start                         # serve the production build
```

## Routes

| Route | What it is |
|-------|------------|
| `/` | Canvas of project nodes, pan + zoom. Below 768px it falls back to a vertical list grouped by client cluster. |
| `/kerja/[slug]` | Cream reading page, statically generated for every `tier: 'full'` project. Fixed seven-block anatomy. |
| `/kontak` | Contact details and CV download. |
| `/opengraph-image` | 1200x630 social card, generated by `next/og`. |
| `/icon` | 64x64 favicon, generated by `next/og`. |

## Editing content

| What | Where |
|------|-------|
| Every project (canvas position, tier, access, copy) | `src/lib/data/projects.js` |
| Contact info, socials, canonical `siteUrl`, CV path | `src/lib/data/meta.js` |
| UI strings | `src/lib/i18n/{id,en}.js` |
| Default locale | `src/lib/i18n/config.js` → `DEFAULT_LOCALE` |
| Colour tokens | `src/app/globals.css` → `@theme` |
| CV file | drop `Utsman-CV.pdf` in `public/` |
| Screenshots | `public/assets/img/` |

`meta.siteUrl` is the single source of truth for the canonical URL — `metadataBase`, the JSON-LD, and the OG card all read it. Do not hardcode a domain anywhere else.

## Adding a project

Append to the array in `src/lib/data/projects.js`:

```js
{
  slug: 'unique-slug',
  client: 'Client Name',
  year: '2026',
  role:   { id: 'Pengembang tunggal', en: 'Sole developer' },
  cluster: 'nirwana',        // groups the node on the canvas and in the mobile list
  tier: 'full',              // 'full' -> big node + /kerja/[slug]; 'brief' -> node + preview only
  access: 'public',          // 'public' | 'internal' | 'none'
  site: 'https://...',       // or null
  position: { x: 560, y: 320 },
  related: ['other-slug'],   // draws an edge on the canvas
  image: '/assets/img/foo.png',  // or null -> designed empty state
  tech: ['Laravel', 'MySQL'],
  shortName: { id: '...', en: '...' },
  title:     { id: '...', en: '...' },
  context:   { id: '...', en: '...' },
  built:     { id: ['...'], en: ['...'] },
  hard:      { id: '...', en: '...' },
}
```

A `full` entry generates its own static page via `generateStaticParams`; a `brief` entry only ever appears as a node.

## Design tokens

Defined in `src/app/globals.css` via Tailwind 4 `@theme`:

| Token | Value | Use |
|-------|-------|-----|
| `--color-paper` | `#F2EDE3` | Reading-page background |
| `--color-paper-deep` | `#E7E0D0` | Paper variant |
| `--color-ink` | `#1A1A1A` | Paper text |
| `--color-mute` | `#6B6B5E` | Paper secondary text |
| `--color-rule` | `#D9D0BC` | Paper borders |
| `--color-ground` | `#161A1D` | Canvas background |
| `--color-ground-soft` | `#1F2529` | Canvas surface |
| `--color-ground-ink` | `#E8E0D0` | Canvas text |
| `--color-ground-mute` | `#7A8580` | Canvas secondary text |
| `--color-ground-rule` | `#2E3539` | Canvas borders |
| `--color-amber` | `#C97B3F` | Accent **on the canvas only** (5.33:1 on ground) |
| `--color-amber-ink` | `#9C5A28` | Accent **on paper** (4.61:1; plain amber fails AA there) |

There is no dark/light toggle. The canvas is dark and the reading pages are cream by design, not by preference.

## Motion contract

Split deliberately. Drag and zoom track the pointer 1:1 with no easing. Anything that moves on its own — the preview panel, page transitions — fades over 700ms `cubic-bezier(0.22, 1, 0.36, 1)`.

## No unsourced claims

Impact numbers were dropped rather than invented. Evidence is the screenshot and the live URL; access status is stated plainly instead of implied. HRIS has no payroll or finance module — do not describe one.

## i18n contract

`src/lib/i18n/__tests__/dictionary.test.js` enforces both locales sharing the same top-level keys. Adding a key to `id.js` requires adding it to `en.js` and vice versa.

## Cross-machine resume

State persists in `docs/PROGRESS.md` (committed). A new session reads PROGRESS to find what is finished, what is outstanding, and the decisions that are expensive to forget.
